## 1. 产品定位（一句话）

**单空间工作操作系统**，在一个标签页里"零跳转"闭环「想 → 拆 → 做 → 记 → 学 → 奖」。

- 核心价值主张：**零跳转**——做一件事所需的需求澄清、步骤、文档、资料、记录、汇报都在同一空间闭环。
- 目标用户：职场新人 / 实习生（管任务、出周报、写文档）+ 备考 / 自学人群（排学习计划、打卡、复盘）。本质是同一个人的两种身份。
